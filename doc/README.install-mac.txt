SonoBusMendeni is a customized version of the original SonoBus project and shared under same terms.

install-macos-standalone.sh - install Standalone app to /Applications.

install-macos-vst3.sh - Run via sudo to install VST3 to /Library/Audio/Plug-Ins/VST3/SonoBusMendeni.

See https://github.com/mendeni/sonobus for projet details.
